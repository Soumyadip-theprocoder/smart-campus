# Tech Stack

## Frontend
- **Framework**: React.js 18.2.0
- **Build Tool**: Vite 8.0.10
- **Routing**: React Router DOM 7.15.0
- **HTTP Client**: Axios 1.16.0
- **Icons**: React Icons 5.6.0
- **Styling**: Vanilla CSS (`index.css`), potentially with component-level styles.

## Backend
- **Language**: Python 3.10+
- **Framework**: Django 4.2.x
- **API**: Django REST Framework (DRF) 3.14+
- **Authentication**: JWT (djangorestframework-simplejwt 5.3)
- **Computer Vision**: OpenCV (`opencv-python-headless`), `face_recognition` (dlib CNN)
- **Server**: Gunicorn 21.2
- **Environment**: `python-decouple`, `django-environ`

## Database
- **Primary**: PostgreSQL (via `psycopg2-binary`)
- **Fallback/Dev**: SQLite (default configuration)
