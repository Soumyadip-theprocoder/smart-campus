# System Requirements (v1.0 Archived)

## Functional Requirements
- [x] **Authentication**: JWT-based secure login, role-based routing (Admin, Faculty, Student).
- [x] **Attendance Management**: AI-based marking, manual override capabilities, and shortage tracking. Plus QR code fallbacks.
- [x] **Scheduling**: Generation of weekly timetables considering faculty and room constraints. Plus advanced transit and elective constraints.
- [x] **Notices & Communication**: Creation and priority-coding of digital notices, with optional email alerts.

## Non-Functional Requirements
- [x] **Performance**: Real-time face detection and API response times under 200ms. Solved via asynchronous processing and db indexing.
- [x] **Scalability**: Capable of handling thousands of student records and large timetable grids. Solved via pgvector and GIN indexes.
- [x] **Deployment**: Production-ready deployment setup via Render (backend) and a static host for the Vite frontend.
